Client Configuration

Add to ~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "morgenruf": {
      "url": "{{ mcp_endpoint }}",
      "headers": {
        "Authorization": "Bearer mrn_YOUR_KEY_HERE"
      }
    }
  }
}

Add to ~/.cursor/mcp.json

{
  "mcpServers": {
    "morgenruf": {
      "url": "{{ mcp_endpoint }}",
      "headers": {
        "Authorization": "Bearer mrn_YOUR_KEY_HERE"
      }
    }
  }
}

Add to .vscode/mcp.json (workspace) or user settings

{
  "servers": {
    "morgenruf": {
      "type": "http",
      "url": "{{ mcp_endpoint }}",
      "headers": {
        "Authorization": "Bearer mrn_YOUR_KEY_HERE"
      }
    }
  }
}

Raw HTTP, useful for testing or custom integrations

curl -X POST {{ mcp_endpoint }} \
  -H "Authorization: Bearer mrn_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"tools/list","id":1}'

How long a chat should be

            
Used in the introduction and when suggesting times.

          

          

            
          

        


        

          

          

            
Where they meet

            

              A room everyone can use, pasted once — a Meet, Zoom or Teams link.
              It appears in every introduction. Leave it empty and people sort it out themselves.
            

          

          

            
          

        


        

          

          

            
Only match people whose hours overlap

            

              Requires an hour of shared working day, from each person's timezone.
              Leave this off for a team spread across distant zones: a nine-to-five in
              Toronto and one in Kolkata share no hours at all, so nobody would be matched.
            

          

          

            
          

        

            


            

              

                

                

                  
Suggest times they could both make

                  

                    Three slots inside everyone's working day, each in both people's own
                    clocks, with one tap to accept. When both accept the same slot the bot
                    settles it. Nobody's calendar is read, so the times are proposals.
                  

                

                

                  
                

              


              

                

                

                  
Open with a question

                  

                    An icebreaker in every introduction, and a menu entry to ask for a
                    different one. Twenty-four of them, so asking twice still gives
                    something new.
                  

                

                

                  
                

              


              

                

                

                  
Post the round's results in the channel

                  

                    After each round, how many pairs met, in the channel rather than only
                    on this page. Teams that see it tend to answer the check-in.
